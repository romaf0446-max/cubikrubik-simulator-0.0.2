        kybikrubik simulator

Инструкция по использованию симулятора и панели разработчика
1. Обзор проекта
Проект состоит из двух основных файлов:

cubikrubik simulator 0.0.1.html (или simulator.html) – полноценный симулятор кубика Рубика с 3D-графикой и чат-ботом.

dev.html – панель разработчика, предназначенная для редактирования кода симулятора, проверки файловой структуры и управления состоянием симулятора.

Оба файла должны находиться в одной папке. Для корректной работы рекомендуется запускать их через локальный HTTP-сервер (например, python -m http.server в каталоге проекта). При открытии напрямую через file:// часть функций (особенно связанных с файловой системой и загрузкой кода) может быть недоступна.

2. Симулятор кубика Рубика
2.1. Запуск
Откройте файл симулятора в браузере. При загрузке отображается короткая анимация: название и миниатюрный кубик перемещаются по экрану, после чего появляется основной интерфейс.

2.2. Элементы интерфейса
Верхняя панель:

Заголовок kybikrubik simulator.

Выпадающий список выбора размера кубика: 2x2, 3x3, 4x4, 5x5.

Кнопка «Сбросить» – мгновенно возвращает кубик в собранное состояние.

Область 3D-вида:

Отображает кубик Рубика.

Вращение камеры осуществляется перетаскиванием указателя мыши (или пальца на сенсорных экранах).

Панель управления:

Содержит кнопки всех доступных ходов.

Для размера 3x3 доступны: U, U', D, D', L, L', R, R', F, F', B, B', M, M', E, E', S, S'.

Для размеров 4x4 и 5x5 дополнительно появляются внутренние слои: 2R, 2L, 2U, 2D, 2F, 2B (и их инверсии).

Для размера 2x2 внутренние и средние слои недоступны.

Чат-панель (расположена в правом нижнем углу):

Поле ввода сообщения.

Кнопка отправки.

Кнопка «ИИ: перемешать» для быстрого перемешивания кубика.

2.3. Использование
Выбор размера: измените значение в списке; кубик будет пересоздан с выбранным размером.

Повороты: нажимайте на кнопки с названием хода. Анимация поворота выполняется плавно; при быстрых последовательных нажатиях ходы ставятся в очередь.

Сброс: кнопка «Сбросить» полностью перестраивает кубик в исходное собранное состояние.

Перемешивание: нажмите кнопку «ИИ: перемешать» или напишите ИИ сообщение «перемешай».

Общение с ИИ: введите текст в чат и нажмите Enter или кнопку отправки. ИИ поддерживает множество тем: приветствия, вопросы о кубике, шутки и т.д.

Вращение камеры: зажмите левую кнопку мыши (или палец) на 3D-области и перемещайте указатель.

3. Панель разработчика (dev.html)
3.1. Запуск
Откройте dev.html в браузере (рекомендуется Chrome или Edge). Панель автоматически проверяет, открыт ли симулятор (через localStorage). Если симулятор не найден, он будет открыт в новой вкладке. Далее панель пытается загрузить код из файла simulator.html (или cubikrubik simulator 0.0.1.html) в редактор.

3.2. Элементы интерфейса
Строка состояния: показывает, найден ли симулятор, и результат проверки наличия папки cubikrubik simulator 0.0.1.

Область дерева файлов: отображает содержимое выбранной папки или структуру открытого ZIP-архива.

Редактор кода: текстовое поле для просмотра и редактирования файлов.

Кнопки:

Открыть папку проекта – выбрать локальную папку и просмотреть её содержимое.

Открыть ZIP-архив – выбрать ZIP-файл и просмотреть его содержимое.

Сканировать ZIP-архивы в папке – рекурсивно искать ZIP-архивы в выбранной папке и проверять, содержится ли в каждом из них папка cubikrubik simulator 0.0.1.

Сохранить текущий файл – сохранить изменения в файле, выбранном из обычной папки (не работает для файлов внутри ZIP).

Загрузить код simulator.html – повторно загрузить код симулятора в редактор.

Запустить – отправить содержимое редактора в открытый симулятор, полностью заменив его код.

Chaos – активировать в симуляторе режим мигания (до перезагрузки страницы).

Проверить снова – обновить строку состояния.

3.3. Редактирование и запуск кода
Откройте dev.html.

Чтобы загрузить код симулятора, нажмите «Загрузить код simulator.html» или выберите файл из дерева.

Внесите изменения в редакторе.

Нажмите «Запустить» – симулятор в соседней вкладке будет перезаписан новым кодом.

Если вы работали с обычным файлом из папки, можно сохранить изменения кнопкой «Сохранить текущий файл».

3.4. Проверка наличия папки cubikrubik simulator 0.0.1
В обычной папке: после нажатия «Открыть папку проекта» панель проверяет, есть ли в выбранной папке подпапка с именем cubikrubik simulator 0.0.1. Результат отображается в строке состояния.

В ZIP-архиве: после открытия ZIP автоматически выполняется проверка на наличие внутри этой папки.

Сканирование ZIP в папке: кнопка «Сканировать ZIP-архивы в папке» рекурсивно обходит все подпапки выбранного каталога, находит все файлы .zip и проверяет, есть ли в них указанная папка.

4. Требования и ограничения
Браузер: рекомендуется Google Chrome или Microsoft Edge (полная поддержка File System Access API).

Для работы панели разработчика с локальными файлами необходимо открывать dev.html через HTTP-сервер.

Функция сохранения файлов работает только для обычных файлов, но не для содержимого ZIP-архивов.

Режим Chaos снимается перезагрузкой страницы симулятора.

Для работы 3D-графики требуется подключение к интернету (загрузка библиотеки Three.js с CDN). При отсутствии интернета симулятор не загрузится.

5. Частые проблемы
Симулятор не открывается: убедитесь, что файл называется правильно и запущен через сервер.

Кнопки не работают: проверьте, не открыт ли симулятор в старой вкладке с устаревшим кодом; перезагрузите страницу.

Панель разработчика не видит файлы: используйте Chrome/Edge и запустите через http://.

ZIP-сканирование не находит папку: убедитесь, что внутри ZIP действительно есть папка с точным именем cubikrubik simulator 0.0.1 (регистр учитывается).
